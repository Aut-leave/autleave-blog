## 怎么写一篇新文章

在 `blog` 目录下打开命令行，运行：

```bash
hugo new posts/我的文章标题.md
```

会生成一个带好前置信息的文件，把 `draft: true` 改成 `false`（或者写完后直接删掉这一行），再写正文。

## 支持的写法

正文用 Markdown，常用语法都支持：

- **加粗**、*斜体*、`行内代码`
- 列表、引用、表格、代码块
- 图片：`![说明](图片地址)`

> 有意思的东西值得被记下来，哪怕只有自己看。

## 本地预览

```bash
hugo server -D
```

打开 `http://localhost:1313`，改文件会自动刷新。看完按 `Ctrl+C` 退出。
